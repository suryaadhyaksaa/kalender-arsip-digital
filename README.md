# Kalender Kegiatan & Arsip Digital

Sistem manajemen kalender kegiatan dan arsip dokumen digital berbasis Next.js (App Router), TypeScript, Tailwind CSS, dan Supabase (PostgreSQL, Auth, Storage).

## 🚀 Fitur Utama
- **Publik**: Beranda interaktif, kalender bulanan/daftar, detail agenda lengkap dengan peta waktu WIB (Asia/Jakarta), serta mesin pencari dokumen arsip digital.
- **Admin**: Proteksi rute berbasis middleware, CRUD agenda lengkap, status draf/publikasi, upload poster, serta pengelolaan dokumen terlampir (PDF, DOCX, XLSX, PPTX, JPG, PNG).
